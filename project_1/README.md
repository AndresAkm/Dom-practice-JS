Ejercicio: Lista de tareas sencilla

Crea una página con:

Un <input> para escribir una tarea.
Un botón "Agregar".
Una lista (<ul>).
Requisitos
Al escribir una tarea y presionar Agregar:
Si el input está vacío, no agregues nada.
Crea un <li> con el texto de la tarea.
Limpia el input.
Cada <li> debe tener:
El texto de la tarea.
Un botón Eliminar.
Cuando se pulse Eliminar:
Se elimina únicamente esa tarea.

Agrega un <p> que muestre:

Tareas pendientes: X

Debe actualizarse cada vez que agregues o elimines una tarea.

Extra (si te sobra tiempo)
Al hacer clic sobre el texto de una tarea:
Se marca como completada (por ejemplo, tachándola con text-decoration: line-through).
Si vuelves a hacer clic, se desmarca.
El contador debe mostrar solo las tareas no completadas.

Esto estará super divertido
